# Froggy Hop 🐸

A one-file retro arcade hopper. Guide a brave little frog across endless roads and rivers — **swipe to hop, tap to hop forward**. Don't get splat, splashed, or left behind!

## How to play

- **Swipe** up / down / left / right — hop one tile in that direction
- **Tap** — hop forward
- Dodge the neon cars on the road 🚗
- Ride the logs across the river 🪵 (don't drift off!)
- Chain quick hops for **combo bonuses**

## Features

- Endless procedurally generated roads, rivers and grass
- Log-riding physics with drift-off danger
- Combo scoring with rising-pitch sound effects
- Retro pixel UI (Press Start 2P) over a smooth neon world
- 3-2-1-GO countdown, pause, mute, persistent best score (`localStorage`)
- Mobile-friendly portrait layout, keyboard support (arrows/WASD, `Space`, `P`, `M`)

## Run it

Just open `index.html` in a browser — no build step, no dependencies.

## Deploy

Static site. Works on any static host (Vercel, Netlify, GitHub Pages).
